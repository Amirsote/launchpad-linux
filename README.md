HELLO!

This is a program I made called "Launchpad", built with Python and GTK. It has the capability to:
- Show a full-screen overlay displaying all your installed system applications dynamically.
- Provide real-time search filtering.

**Dependencies:**
`sudo apt install python3 python3-gi gir1.2-gtk-3.0 shc` (Only for Debian/Ubuntu/Mint and derivatives)

**How to use:**
Open `launchpad_bin` and that is all. If you want a `.desktop` shortcut for your menu or Plank dock, use the `BINARY_TO_DESKTOP` guide provided in this repository. *(If needed, use Google Translate)*

HOLA!

Este es un programa llamado "Launchpad", hecho con Python y GTK. Tiene la capacidad de:
- Mostrar una interfaz de pantalla completa con todas tus aplicaciones instaladas de forma dinámica.
- Filtrar las aplicaciones en tiempo real mediante búsqueda.

**Dependencias:**
`sudo apt install python3 python3-gi gir1.2-gtk-3.0 shc` (Solo para Debian/Ubuntu/Mint y derivados)

**Cómo usar:**
Abre `launchpad_bin` y listo. Si quieres un acceso directo `.desktop` para tu menú o el dock de Plank, usa la guía `BINARY_TO_DESKTOP` que dejé en el repositorio.
